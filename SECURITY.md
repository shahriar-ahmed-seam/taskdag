# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability within TaskDAG, please report it responsibly by contacting the maintainers directly or opening a confidential security advisory on GitHub.

Please include:
- A description of the vulnerability.
- Minimal reproduction steps or code example.
- Affected components or versions.

We investigate all legitimate reports and provide patches prior to public disclosure.
